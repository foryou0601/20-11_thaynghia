HƯỚNG DẪN CHẠY TRÊN VS CODE - THIỆP CHÚC MỪNG 20/11 THẦY NGHĨA
=====================================================================

1. CẤU TRÚC THƯ MỤC:
   - index.html             : Giao diện chính của trang web
   - css/style.css          : Toàn bộ hiệu ứng nền, khung ảnh đính ghim & giao diện thư
   - js/script.js           : Logic mở thiệp, âm thanh & hiệu ứng bắn hoa full màn hình
   - assets/music/          : Bỏ file nhạc của bạn vào đây và đặt tên là "nhac-nen.mp3"
   - assets/images/         : Bỏ 1 tấm ảnh kỷ niệm cùng Thầy Nghĩa vào đây và đặt tên là "anh-thay-nghia.jpg"

2. CÁCH CHẠY TRÊN VS CODE:
   - Mở thư mục này bằng VS Code -> Chuột phải vào file "index.html" -> Chọn "Open with Live Server".
